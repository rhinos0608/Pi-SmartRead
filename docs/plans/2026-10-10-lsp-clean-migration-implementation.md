## Contract decisions

- Canonical document preparation returns submitted-state receipts, never attempted-state freshness. One preparation path, no `prepareDocumentWithReceipt` alternate. Opaque connection/transport/store/document identities remain internal; local submission is not server acknowledgement.

- SmartEdit checks that generation precondition against the exact source content used at stage and again at apply, including when the origin document is not itself edited. Existing read authority, staged-file checks, transaction ownership and UTF-16 enforcement remain independent.
